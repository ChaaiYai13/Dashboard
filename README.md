# ระบบติดตามงาน (Task Tracking System)

ระบบติดตามงานและโครงการ (Task Tracking System) เชื่อมต่อ Google Sheets และ Google Apps Script

## ✨ ฟีเจอร์หลัก
- แดชบอร์ดสรุปผลภาพรวม Real-time
- แผนภูมิวงแหวนสถานะงาน (Donut Chart)
- กราฟแท่งจำแนกตามผู้รับผิดชอบ
- ตารางงานพร้อมระบบค้นหาและตัวกรองสถานะ
- มุมมองจำลอง Google Sheet และระบบส่งออก CSV
- ระบบแจ้งเตือนอัตโนมัติผ่านอีเมล (Automated Alerts)

## 🚀 เริ่มต้นใช้งาน
1. ติดตั้งไลบรารี: npm install
2. รันระบบ: npm run dev
3. เปิดบราวเซอร์ที่: http://localhost:3000
